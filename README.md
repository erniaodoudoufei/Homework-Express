# Homework Express · 学科网作业直达

按学生姓名，一键打开这个学生所用教材的**组卷网章节选题**、**组卷网智能组卷**、**学科网资源**页面。

## 安装

1. 打开 Chrome 的 `chrome://extensions`，打开右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录下的 `extension` 文件夹。
3. 建议在拼图图标里把「作业直达」固定到工具栏。

本插件只在你自己的浏览器里运行，学生和教材数据只保存在本机 Chrome 中，不会上传到任何地方。

## 日常使用

- 按 `Alt+Shift+Z` 或点工具栏图标打开面板，输入姓名或拼音首字母（如「张三」输入 `zs`）。
- 点 **章节选题 / 智能组卷 / 学科网** 按钮打开对应页面。也可以用键盘：`Enter` 打开章节选题，`Ctrl+Enter` 打开智能组卷，`Shift+Enter` 打开学科网。
- 按住 `Ctrl` 点按钮会在后台打开，面板不关，可以连续打开几个页面。
- 在地址栏输入 `zy 张三` 后回车，直接打开章节选题；输入 `zy 张三 智能` 打开智能组卷。
- 智能组卷的网址本身不记录教材，插件打开后会**自动点选该学生的教材版本**，并滚动到对应年级。

## 颜色与筛选

学生按年级自动配色：每一行左边有色条，名字前有同色的圆形头像。高中按教材册别配色，不按年级。

| 小学 | 七年级 | 八年级 | 九年级 | 必修一 / 二 / 三 | 选必一 / 二 / 三 | 其他（自定义链接等） |
|---|---|---|---|---|---|---|
| 绿 | 青 | 蓝 | 紫 | 橙 / 棕黄 / 砖红 | 玫红 / 品红 / 酒红 | 灰 |

颜色由档案的年级决定，年级为空时看档案名称（如「北师大·八上」「人教A版·必修一」），不用手动设置。同一年级的上下册颜色相同。

搜索框下面有一排颜色标签，比如「八年级 5」。点一下就只看这一组，再点一下恢复全部；也可以和搜索一起用。

## 试题篮提醒

从插件打开组卷网（章节选题或智能组卷）时，插件会检查**试题篮**和**组卷草稿**里有没有上次留下的题。有的话，页面顶部会出现提示条：

> 试题篮里还有 8 道、组卷草稿里还有 11 道之前的题，会和这次的作业混在一起。　[一键清空]　[保留]

- **一键清空**：同时清空试题篮和组卷草稿，用的是组卷网自己的删除功能。等同步到服务器后页面会刷新，显示「✓ 已清空」；智能组卷的教材仍保持选好的状态。清掉的题 15 天内可在组卷网【我的 - 选题记录】找回。
- **保留**：关掉提示，什么也不动。
- 两边都是空的就不会提示；不经过插件、直接在组卷网里翻页也不会提示。
- 试题篮按学段区分（初中数学、高中数学各一个），在哪个学段的页面清空，就只清那个学段。
- 不想要这个提醒，可以在 ⚙ 页关掉「从插件打开组卷网时检查试题篮」。

## 添加学生（每种教材只需设置一次）

1. 在组卷网点「章节选题」，选好版本和年级，比如浙教版 → 九年级上册，复制浏览器地址栏里的网址。
2. 打开面板，依次点 ⚙ →「＋ 新建档案」，填上档案名称（如 `浙教版.九上`，句点会自动变成 `·`），把网址粘贴到「章节选题网址」，保存。
3. 保存后插件会自动读取这个页面，补全教材编号、年级、智能组卷网址和学科网网址，其余各项都不用填。
   也可以直接在这个章节选题页上打开面板，点「用当前页面填入」。
4. 点「＋ 学生」，输入姓名，选择教材档案，保存。

教材相同的学生共用一个档案；学生升到下学期时，只要给他换一个档案。改了档案的章节选题网址（换了书）时，年级和学科网网址也会按新书自动更新。

### 不用学科网的学生

档案里的三个网址可以填任意网页，比如 ChatGPT 或 Claude 的对话。展开档案表单底部的「自定义按钮名称」，给按钮起名（如「Claude 作业」「ChatGPT 备课」）。网址留空的按钮不会显示。

## 备份

数据只保存在这台电脑的 Chrome 里。换电脑或重装插件前，请在 ⚙ →「导出备份」保存一个 JSON 文件，之后用「导入备份」恢复。导入会**整体替换**这台电脑上原有的学生和档案，不是合并。备份文件里有学生的姓名和地区，请不要发到公开的地方。

**升级插件时**：把新文件覆盖到原来的 `extension` 文件夹，然后在 `chrome://extensions` 里点插件上的「重新加载」按钮。**不要先「移除」再重新加载**：移除插件会连同所有学生和教材数据一起删掉。

## 说明

- 快捷键冲突时，可以在 `chrome://extensions/shortcuts` 里修改。
- 插件首次安装时自带示例学生「示例学生」（浙教版·九上），可以编辑或删除。
- 拼音首字母按常用读音生成。多音字搜不到时，在学生的「搜索别名」里补上拼音即可。
